SpendSense

### Personal Expense Tracker

SpendSense is a personal expense management application developed using Java and MySQL. It helps users record, manage and track their expenses efficiently.

## Technologies Used
- Java
- MySQL
- JDBC
- MySQL Connector/J

## Features
- Add expenses
- View expense records
- Manage expense details
- Store expense information in a MySQL database

## Requirements
- Java JDK
- MySQL Server
- MySQL Connector/J

## Installation and Setup

1. Download or clone this repository.
2. Open the project in your preferred Java IDE.
3. Create a MySQL database.
4. Execute the SQL commands from the database file.
5. Configure your MySQL username, password and database URL.
6. Add the MySQL Connector/J dependency.
7. Run the main Java application.

## Database Configuration

Update the database connection details in the Java code according to your local MySQL configuration.
